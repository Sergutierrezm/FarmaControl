# 💊 FarmaControl

FarmaControl es una aplicación de escritorio desarrollada en **Java, JavaFX y MySQL** como proyecto final del **Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM)**.

El sistema permite la gestión de una farmacia, incluyendo productos, clientes, proveedores, usuarios y facturas, con funcionalidades de consulta y listado de datos.

---

## 🚀 Funcionalidades

- Gestión de productos (CRUD)
- Gestión de clientes
- Gestión de proveedores
- Gestión de usuarios con roles
- Gestión de facturas con detalle
- Control de acceso por roles (ADMIN / usuario)
- Listados de información:
  - Clientes registrados
  - Productos disponibles
  - Facturas emitidas
  - Usuarios del sistema

---

## 🛠️ Tecnologías utilizadas

- Java
- JavaFX
- MySQL
- JDBC
- Maven
- Arquitectura MVC + capa Service

## 🗄️ Base de datos

El proyecto incluye el script de base de datos:


### Instalación

1. Abrir MySQL Workbench o similar
2. Ejecutar el script `schema.sql`
3. Se creará la base de datos `FarmaControl`

---

## ▶️ Ejecución del proyecto

1. Clonar el repositorio
2. Importar como proyecto Maven
3. Configurar conexión MySQL en `ConexionBD`
4. Ejecutar `Main.java`
